Privacy Policy

プライバシーポリシー

YouTubeチャンネル「10年後の当たり前」および、その制作に使用する個人用ツール atarimae10-pipeline（以下「本ツール」）における個人情報等の取り扱いについて定めます。

制定日：2026年8月23日

1. 本ツールの性質

本ツールは、運営者本人が、運営者本人の所有する YouTube チャンネル1件のみを対象として利用する、個人用の自動化ツールです。第三者への配布・提供・販売は行っておらず、運営者以外の利用者は存在しません。

2. YouTube API Services の利用

本ツールは YouTube API Services を利用しています。本ツールを利用することにより、運営者は以下に同意しています。

  • YouTube 利用規約：https://www.youtube.com/t/terms
  • Google プライバシーポリシー：https://policies.google.com/privacy

Google のセキュリティ設定ページ（https://myaccount.google.com/permissions）から、本ツールのアクセス権をいつでも取り消すことができます。

3. 取得する情報

本ツールが YouTube API Services を通じて取得する情報は、運営者自身のチャンネルに関する以下のものに限られます。

  • チャンネルおよび動画のメタデータ（タイトル、説明、タグ、公開状態、公開日時）
  • 動画の統計データ（表示回数、クリック率、視聴回数、視聴時間、視聴維持率、登録者数の増減、流入経路）
  • アップロードの実行に必要な認証情報（OAuth 2.0 のアクセストークンおよびリフレッシュトークン）

視聴者個人を特定する情報は取得しません。YouTube Analytics から提供されるデータは、いずれも集計済みの統計値です。

4. 情報の利用目的

  • 運営者自身のチャンネルへの動画のアップロードおよび公開設定
  • 公開した動画の実績を分析し、以後の企画・構成の改善に用いること

上記以外の目的には利用しません。

5. 情報の保存と管理

取得した情報および認証情報は、運営者が管理する個人所有のコンピュータ内にのみ保存します。外部のサーバー、クラウドストレージ、公開リポジトリ等に送信・保管することはありません。

YouTube API Services から取得したデータは、取得から30日以内に更新または削除します。

6. 情報の第三者提供

取得したいかなる情報も、第三者に提供、共有、販売、貸与しません。広告配信その他の目的で第三者に開示することもありません。

7. Cookie等の利用

本ウェブサイトは、Cookie その他の追跡技術を使用していません。アクセス解析ツールも導入していません。

8. 動画の視聴について

YouTube 上で当チャンネルの動画を視聴される場合、その視聴に関するデータの取り扱いは YouTube（Google LLC）のプライバシーポリシーに従います。運営者が視聴者個人を特定できる情報を受け取ることはありません。

9. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更した場合は、本ページに改訂日を記載して掲示します。

10. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネルの概要欄に記載の連絡先までお願いします。
